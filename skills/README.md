# Vibe Coding Skills

Essential skills for effective AI-assisted development.

## Priority Order

1. **🔧 [Tool Integration Knowledge](./tool-integration.md)** - *Most critical* - Know what tools exist and how to use them
2. **👁️ [Code Review Skills](./code-review.md)** - *Critical* - Validate every line of AI-generated code
3. **💡 [Programming Fundamentals](./programming-fundamentals.md)** - *Important* - Catch algorithmic and structural issues
4. **🌿 [Version Control Mastery](./version-control.md)** - *Important* - Safe experimentation with AI changes
5. **🏗️ [Architecture Understanding](./architecture.md)** - *Valuable* - Guide AI toward maintainable designs

## Quick Start

If you're new to vibe coding, study these in order:

1. Start with **Tool Integration** to understand the workflow
2. Master **Code Review** to ensure quality
3. Brush up on **Fundamentals** to guide the AI effectively
4. Learn **Version Control** for safe AI-assisted changes
5. Deepen **Architecture** knowledge for long-term maintainability

## Usage

Reference these guides when:
- You're unsure which tool to use
- You need to validate AI-generated code
- The AI suggests a solution that seems off
- You're planning changes with AI assistance
- You want to improve the quality of AI interactions
