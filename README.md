# Signaux de marché & lead gen local

Market signals and lead generation project.

## Setup

### Environment Variables
Create a `.env` file in the project root with your Mapbox token:

```bash
cp .env.example .env
```

Edit `.env` and add your token:
```
MAPBOX_TOKEN=your_mapbox_token_here
```

### Installation
```bash
# Clone the repo
git clone https://github.com/wivoo-edittmer/signaux-de-marche-lead-gen-local.git
cd signaux-de-marche-lead-gen-local

# Install dependencies (if any)
# npm install or pip install -r requirements.txt
```

## Security
**Never commit `.env` to GitHub.** It contains secrets. This repo has `.env` in `.gitignore`.
